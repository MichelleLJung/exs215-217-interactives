# EXS215 / EXS217 Interactives

Created by Michelle L. Jung, Mesa Community College.

Static collection of teaching tools for Resistance Training and Recovery Techniques and Cardiovascular and Flexibility Training.

## Included

- `/`: instructor directory with direct-link and Canvas-embed copy buttons.
- `/group-stretch/`: Stretch Field Guide, routine planner, rehearsal timer, and printable teaching table.

Existing Workout Builder, Workout Feedback and Clinic Scheduler repositories remain separate. Add their verified production links to the directory as needed.

## Netlify setup

Import this repository from GitHub. Use the main branch, no build command, and publish directory `.`. Choose a site name in Netlify after import. The directory generates links from its actual hostname.

Disable Deploy Previews and branch deploys in Netlify before opening pull requests. Batch approved changes into one production deployment.

## Student work

Plans save only in the current browser and website origin. Saved plans from Chat Sites will not appear here. Export existing routines before switching. PDF output uses the browser print dialog; enable background graphics if shading is omitted.

## Checks before assigning

Confirm video playback and captions, keyboard operation, phone/tablet layout and one printed PDF on the final Netlify URL. This repository contains no student or client records.
